# NOSTRA-ECOMMERCE-WEBSITE

GitHub Description

UrbanAura – Fashion E-Commerce Website

UrbanAura is a responsive fashion e-commerce website built using HTML, CSS, and JavaScript. This project was created as a practical learning project to apply frontend development concepts such as responsive design, navigation, image sliders, product collections, filtering, wishlist interactions, contact forms, and mobile-friendly layouts.

The website includes a modern fashion-focused homepage, product collection page, responsive navigation, promotional sections, newsletter section, and interactive wishlist functionality. The project helped me practice and improve my understanding of HTML structure, CSS styling, responsive layouts, JavaScript DOM manipulation, event handling, and basic UI interactions.

Features
🛍️ Fashion-focused e-commerce design
📱 Fully responsive layout for desktop, tablet, and mobile
🧭 Desktop and mobile navigation menu
🖼️ Hero image slider
❤️ Interactive wishlist/heart button
🔎 Product search and filtering
👕 Product collection section
🎁 Promotional offer section
📧 Newsletter subscription section
📞 Contact page
⚡ JavaScript-based interactions
🎨 Clean and modern user interface
